# CHOMPI Tape — MIDI CC Reference

MIDI implementation details for the chompi-tape firmware. Source: [code/src/ui.h](code/src/ui.h), [code/src/NormalPage.h](code/src/NormalPage.h), [code/src/hardware.h](code/src/hardware.h).

## General behavior

- **Input:** TRS/UART MIDI and USB MIDI are both listened to (UART checked first). Incoming events are filtered to the configured input channel (`midi_ch_in`).
- **Output:** Every message is sent over TRS/UART and USB in parallel, on the configured output channel (`midi_ch_out`).
- **Menu page:** All incoming CCs are ignored while the menu page is open.
- **No echo:** Incoming CC knob moves do not get re-sent as outgoing CCs. Outgoing knob CCs are only generated by physical encoder turns.
- **Startup:** All input is ignored for the first ~1.5 s after boot.

## Incoming CCs

### CC 20–25 — Knob control (absolute)

These set the value of the knob at that position, controlling whichever function is on the knob's **current page** (pages are switched by clicking the encoders).

| CC | Value | Effect |
|---|---|---|
| 20 | 0–127 | SPEED knob (absolute 0.0–1.0). Page 1: speed / global pitch. Page 2: sample gain. |
| 21 | 0–127 | START knob (absolute 0.0–1.0). Page 1: sample start point. Page 2: envelope attack. |
| 22 | 0–127 | END knob (absolute 0.0–1.0). Page 1: sample end point. Page 2: envelope decay. |
| 23 | 0–127 | MAGIC knob (absolute 0.0–1.0). Page 1: reverb/delay. Page 2: lofi (saturate). Page 3: filter. |
| 24 | 0–127 | TRANSPORT knob: looper pitch. **Ignored entirely if the looper is not playing.** |
| 25 | 0–127 | GAIN knob (absolute 0.0–1.0). Page 1: master gain. Page 2: input gain. |

Notes:
- The value is applied as `value / 127`, then clamped to 0.0–1.0.
- Start point is never allowed to exceed end point − 0.01; disallowed moves revert to the previous value.
- With pitch quantization enabled, speed/looper-pitch values snap to quantized pitches.

### CC 26 / CC 27 — Transport buttons (edge-triggered with hysteresis)

These emulate the physical **play** and **loop** keys. An internal pressed/released state per CC is kept, and events only fire on state changes:

| CC | Value | Effect |
|---|---|---|
| 26 / 27 | 85–127 (top third) | Sets state to "pressed". On a **rising edge** (was released), injects a synthetic key press: CC 26 → play key, CC 27 → loop key. |
| 26 / 27 | 42–84 (middle third) | **Dead zone — nothing happens.** Previous state is kept. |
| 26 / 27 | 0–41 (bottom third) | Sets state to "released". On a **falling edge** (was pressed), injects a synthetic key release. |

Resulting action per edge:

| CC | Edge | Action |
|---|---|---|
| 26 | Rising | `LooperPlayButton(true)` — looper play/pause. Echoes CC 26 = 127 on the output channel. |
| 26 | Falling | `LooperPlayButton(false)`. Echoes CC 26 = 0. |
| 27 | Rising | `LooperRecordButton(true)` — arm/toggle looper recording (skipped while a sample recording is in progress). Echoes CC 27 = 127. |
| 27 | Falling | `LooperRecordButton(false)`. Echoes CC 27 = 0. |

Because the logic is edge-triggered, sending 127 repeatedly only triggers once — you must send a value ≤ 41 before another value ≥ 85 will re-trigger. The 42–84 dead zone prevents chatter from noisy continuous controllers.

## Outgoing CCs

### Encoder values (absolute 0–127)

Physical encoder turns send `value * 127` on the CC assigned to the knob's **current function** (the CC changes when the knob page changes):

| Function | Knob | Knob page | CC | Value |
|---|---|---|---|---|
| Speed / global pitch | SPEED | 1 | 20 | 0–127 absolute |
| Sample gain | SPEED | 2 | 28 | 0–127 absolute |
| Sample start point | START | 1 | 21 | 0–127 absolute |
| Envelope attack | START | 2 | 29 | 0–127 absolute |
| Sample end point | END | 1 | 22 | 0–127 absolute |
| Envelope decay | END | 2 | 30 | 0–127 absolute |
| Reverb / delay | MAGIC | 1 | 23 | 0–127 absolute |
| Lofi (saturate) | MAGIC | 2 | 31 | 0–127 absolute |
| Filter | MAGIC | 3 | 33 | 0–127 absolute |
| Looper pitch | TRANSPORT | 1 | 24 | 0–127 absolute |
| Master gain | GAIN | 1 | 25 | 0–127 absolute |
| Input gain | GAIN | 2 | 32 | 0–127 absolute |

Additionally, resetting the looper pitch (transport encoder click) sends CC 24 with the default value (≈ 95).

### Key CCs (momentary 127 / 0)

| Key | CC | Press | Release |
|---|---|---|---|
| Play key | 26 | 127 | 0 |
| Loop key | 27 | 127 | 0 |
| Chompi key | 21 | 127 | 0 |

Chompi key quirk: it only sends CC 21 when the toggle switch is in the "keys" position; in the other position, holding the chompi key instead shifts the MIDI output channel by one while held. Note this CC 21 collides with the "sample start point" CC number.

## Notes (non-CC)

- **Incoming:** Note On/Off in the range 24–72 maps through a lookup table onto the 25 keys; velocity is passed through to the voice. Notes outside that range are ignored.
- **Outgoing:** Key presses send Note On / Note Off with note numbers 48–72 (per `key_map`) at velocity 127.
